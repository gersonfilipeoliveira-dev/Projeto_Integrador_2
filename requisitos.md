Requisitos principais do projeto

Requisitos funcionais:

O sistema deve permitir cadastrar as modalidades esportivas.
O aluno deve poder votar em uma ou mais modalidades.
O sistema deve registrar os votos.
O sistema deve mostrar a quantidade de votos de cada esporte.
O sistema deve apresentar quais modalidades foram mais votadas.
Cada aluno deve poder votar apenas uma vez.

Requisitos não funcionais:

O sistema deve ser simples e fácil de usar.
Deve funcionar em computadores e celulares.
Os resultados devem ser apresentados de forma clara.
A votação deve impedir votos duplicados.
