# Projeto_Integrador_2
Problem: Alunos sem participar dos jogos escolares por conta de poucas opções de esportes.

Muitos alunos não participam dos jogos escolares por conta das poucas opções de esportes.
Sempre os mesmos, Futsal e Volêi. lguns alunos podem ter talentos em outros esportes como queimada e handebol..

Solução: Seleção de esportes nos jogos esolares por votação dos alunos.
